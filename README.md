# HireMe – AI-Powered Career Matching Platform

## Overview

HireMe is a recruitment platform developed as a **final-year creative research project**.
It addresses graduate unemployment in South Africa by using **AI-powered skill translation and job matching**.
The system benefits both **students** (by simplifying applications and tailoring CVs) and **employers** (by reducing irrelevant applications and improving candidate quality).

---

## Key Features

- **Student-Facing**
  - Profile management with CV & transcript upload
  - AI skill extraction & academic-to-industry translation
  - Smart job matching with transparency (match scores & explanations)
  - One-click applications with AI-generated cover letters
  - Application tracking & feedback loop with skill gap analysis

- **Employer-Facing**
  - Employer dashboard with job posting tools
  - Candidate browsing & proactive recommendations
  - BEE compliance filters & diversity analytics
  - Application review with AI-generated candidate summaries
  - Direct messaging & recruitment analytics

- **AI Capabilities**
  - Claude API for skill extraction, semantic matching, and cover letter generation
  - Sentiment analysis for cultural fit
  - Feedback-driven improvement loop

---

## Tech Stack

- **Frontend:** React (responsive design, CSS styling)
- **Backend:** Firebase (Authentication, Firestore, Cloud Storage, Cloud Functions, Hosting)
- **AI Integration:** Claude API via RESTful HTTP calls
- **Version Control:** GitHub (feature branch workflow, PR reviews)
- **Deployment:** Firebase Hosting with global CDN & HTTPS

---

## Project Scope

- **In Scope (MVP):** AI-driven job matching, CV tailoring, cover letter generation, application tracking
- **Out of Scope:** Custom model training, gamification, external job board integrations
- **Future Considerations:** Mobile app, offline functionality, advanced analytics, integration with online learning providers
